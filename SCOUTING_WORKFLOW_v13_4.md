# Slot Map v13.4.0 scouting workflow

This release improves field use without changing the prediction model.

- Scout Dashboard: Best Leads, My Scout List, Revisit, and Needs Report presets.
- Presets preserve County/City and other non-scouting context so a local session stays local.
- Open Next Best Lead selects the strongest currently matching high-priority unvisited lead.
- Field Reports use four large status buttons plus the existing deliberate Save step.
- AP / Old AP choices focus the game field for faster entry.
- All Machines Checked fills checked/total from the official VGT count when available.
- No AP and Revisit are not auto-saved, reducing accidental reports.
